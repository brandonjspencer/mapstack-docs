# MapStack docs

Public documentation for **[MapStack](https://mapstack.pro)** — a free,
collaborative sitemap builder (build a visual page tree, map user journeys and
off-site entry points, and collaborate live with your team).

- **[User Guide](USER_GUIDE.md)** — how to use the app end to end: building the
  tree, page details, journeys, off-site entry points, collaboration, versions,
  import/export, and keyboard shortcuts.
- **[LLM Import Guide](LLM-IMPORT-GUIDE.md)** — the exact CSV formats plus
  copy-paste prompts for getting an LLM to generate import-ready **sitemap** and
  **journeys** files.

These guides are also available inside the app under **Help & docs** (the
account menu in the top-right).

> This repository is the public, shareable mirror of the guides maintained in
> the MapStack app repository. Open an issue if anything here is out of date.
